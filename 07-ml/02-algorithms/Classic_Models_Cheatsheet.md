# 经典模型速查

## 简介
按"用什么场景选什么模型"组织的速查表。**先看场景，再看模型**——反过来会陷入"手里有锤子看什么都是钉子"。

## 一、按任务选模型

| 任务 | 首选基线 | 进阶 | 备注 |
|---|---|---|---|
| 表格分类/回归 | **LightGBM / XGBoost** | 深度模型（需大数据） | GBDT 仍是表格数据王者 |
| 小样本分类 | 逻辑回归 + 特征 | SVM（核方法） | 可解释、稳定 |
| 时间序列预测 | 统计模型（ARIMA）+ 树模型 | LSTM / TFT / PatchTST | 先看是否真有序列依赖 |
| 异常检测 | Isolation Forest / 3σ | 自编码器、One-Class SVM | 无标签场景首选统计法 |
| 图像分类 | ResNet | EfficientNet / ViT | ViT 需大数据预训练 |
| 目标检测 | YOLO 系 | DETR / 开放词表检测 | 实时优先选 YOLO |
| 图像分割 | U-Net | Mask R-CNN / SAM | 小数据 U-Net 更稳 |
| 文本分类 | 微调 BERT 类 | LLM few-shot | 数据少用 LLM |
| 语义检索 | 专用 embedding 模型 | 微调双塔 | 不要用通用 LLM 做检索 |
| 生成/对话 | LLM（GPT/Claude/Qwen） | 领域微调 | 先提示工程，再微调 |
| 图数据 | GraphSAGE（归纳式） | GAT / 图 Transformer | 先做无图基线 |
| 推荐召回 | ItemCF / 双塔 | 图召回 | — |
| 推荐排序 | DeepFM | DIN / DCN / SASRec | 有行为序列用 DIN |

## 二、按数据量选模型

| 数据量 | 推荐路线 |
|---|---|
| < 1k 样本 | 规则 → 逻辑回归/SVM → LLM few-shot |
| 1k–10 万 | GBDT、微调小模型 |
| 10 万–100 万 | 深度模型、微调中型模型 |
| > 100 万 | 大规模预训练、ViT/Transformer |

## 三、传统模型对照

| 模型 | 类型 | 优点 | 缺点 |
|---|---|---|---|
| 线性回归 | 回归 | 可解释、快 | 只能拟合线性关系 |
| 逻辑回归 | 分类 | 输出概率、稳定 | 需人工特征工程 |
| 决策树 | 通用 | 可解释 | 易过拟合 |
| 随机森林 | 集成（Bagging） | 稳、少调参 | 模型大、推理慢 |
| XGBoost | 集成（Boosting） | 精度高、支持缺失值 | 需调参 |
| LightGBM | 集成（Boosting） | 快、省内存 | 小数据易过拟合 |
| SVM | 分类 | 小样本强 | 大数据慢、核函数难选 |
| K-Means | 聚类 | 简单快 | 需预设 K、只适合球形簇 |
| DBSCAN | 聚类 | 任意形状、能识别噪声 | 密度参数敏感 |
| PCA | 降维 | 快、可解释 | 仅线性 |

## 四、深度模型对照

| 模型 | 结构特点 | 擅长 | 局限 |
|---|---|---|---|
| MLP | 全连接 | 表格、简单映射 | 无结构先验 |
| CNN | 局部卷积 + 权值共享 | 图像、局部模式 | 长程依赖弱 |
| RNN/LSTM | 循环 + 门控 | 序列 | 串行、长依赖衰减 |
| Transformer | 自注意力 | 一切序列，可并行 | O(n²) |
| ResNet | 残差 | 极深 CNN | — |
| ViT | 图像切块 + Transformer | 大数据图像 | 小数据效果差 |
| GNN | 消息传递 | 图结构 | 规模受限、易过平滑 |
| Diffusion | 逐步去噪 | 高质量生成 | 采样慢 |

## 五、选型的第一性问题

选模型前先回答三个问题：

1. **数据是什么形状？** 表格 / 序列 / 图像 / 图 / 文本——形状决定结构。
2. **有多少标注？** 少 → 简单模型或预训练 + 提示；多 → 深度模型。
3. **推理在哪跑？** 云端 → 可以大；边缘 → 必须小（量化/蒸馏）。

**三个问题的答案组合起来，可选范围通常只剩 2–3 个模型。** 剩下的靠实验决定。

## 六、常见误判

- **"深度模型一定更好"**：表格数据上 GBDT 常赢，且训练快十倍；
- **"新模型一定更好"**：新架构的优势往往需要匹配的数据规模与算力；
- **"集成一定更好"**：集成的收益递减，且推理成本线性上升；
- **"预训练模型万能"**：领域差异大时，预训练模型可能不如领域小模型。
