# 自编码器（Autoencoder）

## 简介
自编码器是一种**无监督的表示学习方法**：让网络把输入压缩成一个低维向量（编码），再从该向量还原出原输入（解码），训练目标是**重建误差最小**。

关键认知：**输出本身没有价值**——重建只是手段。真正的产物是中间那个**低维表示**，它被迫保留了输入中最重要的结构信息。

```
x ──编码器 f──▶ z（低维隐向量）──解码器 g──▶ x̂ ≈ x
```

## 核心机制

| 组件 | 作用 | 典型结构 |
|---|---|---|
| 编码器 f | 把高维输入压到低维隐空间 | 若干全连接/卷积层 + 降维 |
| 瓶颈层 z | 表示的核心，维度远小于输入 | 数十到数百维 |
| 解码器 g | 从 z 重建输入 | 与编码器对称的升维结构 |
| 损失 | 重建误差（MSE / BCE / 感知损失） | `||x - x̂||²` |

**为什么压缩能学到东西**：瓶颈限制了信息通道宽度，网络必须优先保留"重建最需要的那部分信息"，噪声和冗余被自然丢弃。这与 PCA 的动机同源，但自编码器是**非线性**的。

## 主要变体

| 变体 | 关键改动 | 解决什么问题 |
|---|---|---|
| 基础 AE | — | 降维、特征提取 |
| 去噪自编码器 DAE | 输入加噪声，目标仍是干净原图 | 迫使模型学鲁棒特征，而非恒等映射 |
| 稀疏自编码器 | 对隐层加稀疏惩罚 | 学出更"局部化"、可解释的特征 |
| 变分自编码器 VAE | 隐空间建模为概率分布，加 KL 正则 | 可采样生成新样本 |
| VQ-VAE | 隐向量量化到离散码本 | 离散表示，配合自回归先验做生成 |

## 与其他方法的对照

| 对比对象 | 关系 |
|---|---|
| PCA | 线性、无激活函数的自编码器，其最优解张成的子空间与 PCA 一致；AE 的价值在于能学非线性流形 |
| 自监督预训练（BERT/MAE） | 思想同源——都是"从数据自身构造监督信号"；MAE 本质是 masked 版本的自编码器 |
| 普通监督学习 | 不需要标签，但学到的表示是否"对任务有用"需要下游验证 |

## 场景 / 优势 / 局限

**适合**
- **异常检测**：正常样本训练，推理时重构误差大的判为异常（工业传感器、设备振动信号），这是自编码器在工业场景最实用的落点；
- **降维与可视化**：替代 PCA 处理非线性数据；
- **去噪**：信号/图像预处理；
- **生成**：仅 VAE 系列适用。

**局限**
- **重构好 ≠ 表示好**：隐空间可能只是记住了输入，对下游任务毫无帮助；
- **过完备隐空间会退化**：若瓶颈维度 ≥ 输入维度，网络可以学成恒等映射，此时毫无压缩价值；
- **VAE 生成偏模糊**：KL 正则使隐空间平滑，代价是样本清晰度；
- **异常检测的阈值难定**：重构误差的分布依赖数据，跨设备迁移困难。

## 实践建议
1. **先跑 PCA 做 baseline**，确认非线性确实带来收益再加自编码器；
2. 异常检测场景中，**用重构误差的分位数定阈值**，并在验证集上校准误报率；
3. 瓶颈维度是关键超参：太小欠拟合、太大退化为恒等映射，从输入的 1/10 起试；
4. 工业时序信号优先用 **1D 卷积自编码器**，比全连接更能捕捉局部波形特征。
