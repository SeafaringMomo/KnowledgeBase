# 机器学习数学基础

## 简介
不需要把数学学到能考试的程度，但**必须知道每个公式在解决什么问题**。这份笔记按"用得上"排序：优化 > 概率 > 线性代数，其余按需查阅。

## 一、线性代数：数据的形状

| 概念 | 在 ML 里对应什么 | 什么时候用 |
|---|---|---|
| 向量 | 一个样本的特征、一个词的 embedding | 一切 |
| 矩阵 | 一批样本、一层权重 | 一切 |
| 张量 | 多维批数据（batch × seq × dim） | 深度学习 |
| 特征值/特征向量 | 变换的主方向 | PCA、谱聚类、稳定性分析 |
| **SVD** | 任意矩阵分解为三个正交矩阵的乘积 | 降维、推荐系统矩阵分解、LoRA 的低秩分解 |
| 矩阵求导 | 反向传播的核心运算 | 推导梯度 |

**必须理解的三个直觉**
1. **矩阵乘法 = 线性变换**：`y = Wx` 是把向量旋转/缩放/投影到另一个空间。
2. **秩（rank）越低，信息越少**：LoRA 正是利用"微调所需的参数更新是低秩的"这一假设，把大矩阵分解成两个小矩阵。
3. **范数衡量"大小"**：L2 范数惩罚大参数（平滑），L1 范数产生稀疏解（特征选择）。

## 二、概率统计：不确定性的语言

| 概念 | 作用 | 典型应用 |
|---|---|---|
| 条件概率 / 贝叶斯公式 | 由先验与似然推后验 | 朴素贝叶斯、贝叶斯优化 |
| 极大似然估计 MLE | 找让数据出现概率最大的参数 | 几乎所有损失函数的来源 |
| MAP 估计 | MLE + 先验 | 等价于 L2 正则 |
| 高斯分布 | 误差的默认假设 | MSE 损失的理论依据 |
| GMM | 多个高斯混合拟合复杂分布 | 聚类、语音特征建模 |
| EM 算法 | 含隐变量时的迭代求解 | GMM、HMM 训练、VAE 的理论前身 |

**关键联系**：**损失函数不是拍脑袋定的**。
- 假设噪声服从高斯分布 → 取负对数似然 → 得到 **MSE**；
- 假设标签服从伯努利/类别分布 → 取负对数似然 → 得到 **交叉熵**。

理解这条推导链，才知道"为什么分类用交叉熵而不是 MSE"（后者在 sigmoid 后梯度会消失）。

## 三、微积分与优化：怎么找到最小值

| 概念 | 含义 | 用途 |
|---|---|---|
| 偏导数 / 梯度 | 函数增长最快的方向 | 梯度下降沿着反方向走 |
| 链式法则 | 复合函数求导 | 反向传播的全部原理 |
| Hessian 矩阵 | 二阶导数，描述曲率 | 牛顿法、判断凸性、分析鞍点 |
| 凸函数 | 局部最优即全局最优 | 逻辑回归、SVM 有全局最优保证 |

**深度学习非凸，那为什么还能训？**
实践中的解释：高维空间里"坏的局部最优"很少，更多是**鞍点**；随机梯度带来的噪声本身有助于逃离鞍点。所以"非凸"不等于"训不动"。

## 四、偏差—方差分解

$$
\mathbb{E}[\text{Error}] = \text{Bias}^2 + \text{Variance} + \text{Noise}
$$

| 症状 | 训练误差 | 验证误差 | 本质 | 对策 |
|---|---|---|---|---|
| **欠拟合（高偏差）** | 高 | 高 | 模型容量不足 | 加参数、加特征、减正则 |
| **过拟合（高方差）** | 低 | 高 | 记住了噪声 | 加数据、加正则、早停、简化模型 |

**这是机器学习里最有用的一张表**：任何"效果不好"的问题，先判断落在哪一格，再谈方法。判断错了，努力全白费。

## 五、误差从哪来：一个常被忽略的事实
模型性能的上限由**数据分布本身的可约误差 + 不可约噪声**决定。当验证误差已经接近噪声水平时，**换模型不会有用**——该去改数据或改问题定义。这条判断能省掉大量无效调参。
