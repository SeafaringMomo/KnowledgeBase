# 项目实战与案例

## 简介
模型知识不等于交付能力。这份笔记把典型项目按**"问题定义 → 技术选型 → 关键坑 → 验收标准"**四段式拆开，作为启动新项目时的检查清单。

## 一、项目启动的五问（先于任何技术选型）

1. **业务指标是什么**？（不是准确率，是漏检率/响应时间/人力节省）
2. **错了会怎样**？（决定要不要人工兜底、能不能接受幻觉）
3. **数据从哪来、有多少、标注谁做**？
4. **部署在哪**？（云端/边缘/离线，决定模型大小上限）
5. **怎么算成功**？（可量化的验收条件+时间点）

> **跳过这五问直接选模型，是项目失败最常见的原因。**

## 二、CV 类项目

### 案例 1：工业缺陷检测（YOLO 系）
| 项 | 内容 |
|---|---|
| 问题 | 产线节拍内检出表面缺陷，漏检率 < 0.5% |
| 方案 | YOLO 检测 + 传统阈值兜底；小目标切图推理 |
| 关键坑 | 缺陷样本极少（长尾）→ 用异常检测补足；光照变化 → 固定光源；误检率高 → 引入二级复核模型 |
| 验收 | 现场实测漏检率、误检率、单张耗时（必须 ≤ 节拍） |

### 案例 2：文档 OCR + 结构化
| 项 | 内容 |
|---|---|
| 问题 | 扫描件/PDF 转结构化字段 |
| 方案 | 版面分析 + OCR + 规则/LLM 抽取 + 校验 |
| 关键坑 | 表格与公式是弱项；盖章遮挡；字段校验必须做（金额合计、编号格式） |
| 验收 | 字段级准确率，且**错误必须可被发现**（置信度 + 人工复核队列） |

### 案例 3：医学/遥感分割
| 项 | 内容 |
|---|---|
| 方案 | U-Net 系 + 预标注 + 主动学习 |
| 关键坑 | 标注成本极高；类别极不均衡；不同设备的域偏移 |
| 验收 | Dice/mIoU + 放射科医生复核通过率 |

## 三、NLP / LLM 类项目

### 案例 4：文本分类（工单分类、舆情）
| 项 | 内容 |
|---|---|
| 方案 | 小数据：LLM few-shot；有标注：微调 encoder |
| 关键坑 | 类别边界模糊（需先定义清晰）；类别不均衡；长文本截断丢信息 |
| 验收 | 宏平均 F1 + 混淆矩阵人工审查 |

### 案例 5：企业知识库问答（RAG）
| 项 | 内容 |
|---|---|
| 方案 | 解析→切块→混合检索→rerank→生成带引用 |
| 关键坑 | 切块切断语义；权限过滤；**答不出来时应拒答而不是编**；文档更新后索引不同步 |
| 验收 | 检索命中率、答案忠实度、拒答准确率（三件事分开评） |

### 案例 6：Agent 自动化
| 项 | 内容 |
|---|---|
| 方案 | 工具定义 + 循环 + 验证器 + 人工确认 |
| 关键坑 | 无限循环（要有 max_steps）；工具描述歧义导致选错；错误被静默吞掉 |
| 验收 | 任务完成率 + 人工接管率 + 单任务成本 |

详见 [Loop Engineering](../../12-ai-agent/01-agent/Loop_Engineering.md)。

## 四、推荐 / 风控类项目

### 案例 7：电商推荐
| 项 | 内容 |
|---|---|
| 方案 | 召回（双塔/ItemCF）→ 精排（DeepFM）→ 重排（规则+多样性） |
| 关键坑 | 冷启动；位置偏差；离线涨线上不涨 |
| 验收 | GAUC（离线）+ CTR/转化（线上 A/B） |

### 案例 8：设备故障预测（时序）
| 项 | 内容 |
|---|---|
| 方案 | 窗口统计特征 + LightGBM 基线；时序模型（LSTM/TFT）对比 |
| 关键坑 | 标签定义（"故障"从哪个时刻算起）；正负样本极不均衡；**预测提前量要与检修周期匹配** |
| 验收 | 提前预警窗口 + 误报率（误报太多会导致现场关掉告警） |

## 五、跨项目的通用陷阱

| 陷阱 | 表现 | 对策 |
|---|---|---|
| **只做 POC 不做交付** | Demo 惊艳，上线无门 | 第一天就定部署形态 |
| **没有基线** | 直接上最复杂模型 | 先跑最简单基线（规则/GBDT/小模型） |
| **评估集缺失** | 靠感觉判断好坏 | 第一周建评测集 |
| **数据泄漏** | 离线指标异常好 | 检查时间与分组划分 |
| **忽视推理成本** | 精度达标但算不起 | 一开始就算单次推理成本 |
| **没有人工兜底** | 错误直接暴露给用户 | 置信度阈值 + 复核队列 |

## 六、验收清单（上线前逐项打勾）
- [ ] 业务指标已定义，且与模型指标对应
- [ ] 独立测试集评估完成，指标含置信区间
- [ ] 推理延迟与成本实测达标
- [ ] 数据漂移监控已配置
- [ ] 回滚方案已演练
- [ ] 人工兜底流程已就位
- [ ] 权限与安全检查（含 Prompt Injection 用例）通过
