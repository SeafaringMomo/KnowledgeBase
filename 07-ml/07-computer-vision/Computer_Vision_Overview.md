# 计算机视觉概览

## 简介
CV 的目标是让机器从像素中提取语义。四条主线：**分类（这是什么）→ 检测（在哪、有几个）→ 分割（每个像素属于谁）→ 生成/理解（重建与描述）**。2012 年 AlexNet 之后，这条线的核心变化是**特征从手工设计（SIFT/HOG）变成网络自学**。

## 一、主干网络演进（分类）

| 模型 | 年份 | 关键贡献 | 遗留影响 |
|---|---|---|---|
| AlexNet | 2012 | GPU + ReLU + Dropout，深度学习起点 | 证明端到端可训 |
| VGG | 2014 | 3×3 小卷积堆叠 | "深度优先"的设计范式 |
| **ResNet** | 2015 | **残差连接**，解决深层退化 | 至今仍是 CNN 的默认骨架 |
| EfficientNet | 2019 | 复合缩放（深度/宽度/分辨率） | 参数效率思路 |
| **ViT** | 2020 | 图像切 patch 当 token，纯 Transformer | 大模型时代的视觉底座 |

**ResNet 为什么重要**：残差 `y = F(x) + x` 让梯度有了一条"高速公路"，使 100+ 层网络可训。这个思想后来被 Transformer 全盘继承。

**CNN vs ViT 的分水岭**：CNN 有归纳偏置（局部性、平移不变），小数据也能学；ViT 没有这些先验，**必须在大数据上预训练**才有效。数据量决定选型。

## 二、目标检测

| 流派 | 代表 | 思路 | 特点 |
|---|---|---|---|
| 两阶段 | R-CNN → Fast → Faster R-CNN | 先出候选框，再分类回归 | 精度高、速度慢 |
| 单阶段 | YOLO 系列、SSD | 一次前向直接出框 | 快，工程首选 |
| 无锚框 / 集合预测 | **DETR** | Transformer 直接预测框集合，去掉 NMS | 结构简洁，小目标较弱 |

**工程实践的分水岭**：
- 需要**实时**（视频流、产线检测）→ YOLO 系列；
- 需要**高精度、离线**（质检复核）→ 两阶段或大模型；
- 需要**开放词表检测**（"找出所有类似阀门的东西"）→ 开放词汇检测（Grounding DINO 等）。

## 三、图像分割

| 类型 | 输出 | 代表 | 场景 |
|---|---|---|---|
| 语义分割 | 每像素类别 | FCN、U-Net、DeepLab | 遥感、医学、缺陷区域 |
| 实例分割 | 每像素 + 实例 ID | Mask R-CNN | 计数 + 分割 |
| 全景分割 | 语义 + 实例统一 | Panoptic 系列 | 自动驾驶 |

**U-Net 的编码器—解码器 + 跳跃连接**结构，在医学影像与小样本分割中长期不可替代——因为跳跃连接保留了高分辨率细节。

## 四、视频与传统视觉

| 方向 | 关键问题 | 常用方法 |
|---|---|---|
| 目标跟踪 | 跨帧保持身份 | 检测 + 匈牙利匹配（SORT/DeepSORT） |
| 行为识别 | 时序动作分类 | 3D CNN、Two-Stream、Video Transformer |
| 视频分类 | 整段视频打标签 | 帧采样 + 时序聚合 |
| 传统 CV | 无需学习的几何处理 | Canny 边缘、Hough 变换、形态学 |

**传统方法并未过时**：几何标定、模板匹配、阈值分割在**强约束工业场景**里往往比深度模型更稳定、更可解释、更快。**能用地标定解决的问题，不要用神经网络。**

## 五、评估指标

| 任务 | 指标 | 注意 |
|---|---|---|
| 分类 | Top-1 / Top-5 Accuracy | 类别不均衡时看 per-class |
| 检测 | mAP@IoU（0.5 / 0.5:0.95）、mAP50 | 报告必须写清 IoU 阈值 |
| 分割 | mIoU、Dice（医学） | Dice 对小目标更敏感 |
| 跟踪 | MOTA、IDF1 | IDF1 衡量身份保持能力 |

## 六、边界与代价

- **数据成本是主要瓶颈**：标注一张分割图可能是分类标注的 50 倍工作量；工业缺陷样本天然稀少（长尾、零样本问题）；
- **域偏移严重**：实验室训练的模型换个光照、换个相机就崩，**部署前的现场数据必须进训练集**；
- **小目标与密集目标**：分辨率与下采样冲突，检测小目标通常需要切图推理（tiling）；
- **可解释性弱**：热力图只能说明"看了哪里"，不等于"依据了什么"；
- **大模型的推理成本**：ViT/多模态模型精度高但延迟高，产线节拍可能不达标。

## 七、实践建议
1. **先做基线**：小模型 + 数据增强跑通，再谈换大模型；
2. **数据增强按场景设计**：工业图像慎用翻转/旋转（会破坏物理合理性），优先亮度、对比度、噪声、局部遮挡；
3. **检测任务的 mAP 不等于业务指标**：漏检率、误报率、单张耗时才是产线语言；
4. **必须做现场验证集**：用真实相机、真实光照、真实节拍采集；
5. 边缘部署优先考虑量化（INT8）与小模型蒸馏，见 [训练与推理优化](../14-mlops/Training_and_Inference_Optimization.md)。
