# 语音处理概览

## 简介
语音处理把"声波"变成"文字"（ASR），或把"文字"变成"声波"（TTS），以及判断"这是谁在说"（声纹）。它的核心难点在于：**音频是连续的高采样率信号，而语言是离散的符号序列**——中间隔着一层特征表示与对齐问题。

## 一、从波形到特征

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 采样 | 连续波形 → 离散点 | 16 kHz 是语音识别常用采样率 |
| 分帧 + 加窗 | 切成 20–30 ms 的短帧 | 假设帧内平稳 |
| 频谱 / STFT | 时域 → 时频图 | 得到频谱图（spectrogram） |
| **Mel 滤波器组** | 按人耳感知非线性压缩频率轴 | 得到 Mel 频谱，是主流输入特征 |
| MFCC | 对 Mel 谱再做离散余弦变换 | 传统特征，去相关、维度更低 |

**为什么用 Mel 而不是原始频谱**：人耳对低频变化敏感、对高频迟钝。Mel 刻度模拟这一特性，用更少的维度保留更多"人听得出来"的信息。

## 二、ASR（语音识别）

| 代际 | 代表 | 关键思路 |
|---|---|---|
| 传统混合系统 | GMM-HMM → DNN-HMM | 声学模型 + 发音词典 + 语言模型分离 |
| 端到端（CTC） | DeepSpeech | 不需帧级对齐，直接输出字符序列 |
| 端到端（注意力） | LAS | 编码器—解码器 + 注意力，可做上下文纠错 |
| **Conformer** | Google 2020 | 卷积（局部）+ 自注意力（全局）结合，精度与效率兼顾 |
| **Whisper** | OpenAI 2022 | 大规模弱监督多语种，鲁棒性强，工程首选 |

**CTC vs 注意力的取舍**：
- **CTC**：单调对齐假设，训练稳定、推理快，但不能利用右侧上下文，也不擅长"听错后自我纠正"；
- **注意力解码**：能利用全局上下文、可注入语言模型，但需要更多数据、可能产生"幻觉式转写"（音频静音却输出文字）。

**Whisper 的工程价值**：多语种、抗噪、开箱即用，做中文识别也表现良好；缺点是**模型较大、实时性一般**，且对领域术语需要热词/提示偏置。

## 三、TTS（语音合成）

| 阶段 | 传统 | 现代 |
|---|---|---|
| 文本前端 | 分词、注音、韵律预测 | 端到端弱化，但**多音字与数字规范化仍必须做** |
| 声学模型 | Tacotron 系列（自回归，慢） | FastSpeech 系列（非自回归，快） |
| 声码器 | WaveNet（音质好、极慢） | HiFi-GAN、 neural vocoder（实时） |

**自回归 vs 非自回归**：Tacotron 逐帧生成，音质好但慢且不稳定（偶尔跳字、重复）；FastSpeech 并行生成，速度快但依赖时长预测的准确性。现代方案多用非自回归 + 高质量声码器。

## 四、声纹识别

| 概念 | 说明 |
|---|---|
| 注册（enrollment） | 用少量语音建立说话人模板 |
| 验证（verification） | 1:1 判断"是不是这个人" |
| 辨认（identification） | 1:N 判断"是库里的谁" |
| x-vector | 经典的说话人 embedding |
| ECAPA-TDNN | 当前主流，多尺度特征聚合，等错误率低 |

**关键指标**：EER（等错误率）、minDCF。**安全场景必须做防录音攻击（anti-spoofing）**，否则一段录音就能冒充。

## 五、评估指标

| 任务 | 指标 | 说明 |
|---|---|---|
| ASR | **WER**（词错误率）/ **CER**（字错误率，中文常用） | `(替换+删除+插入)/总词数` |
| TTS | MOS（主观平均分） | 5 分制人工评分；客观可用 MCD、RTF |
| 声纹 | EER、minDCF | 越低越好 |
| 实时性 | RTF（实时因子） | < 1 才能实时 |

## 六、边界与代价

- **噪声与远场是最大杀手**：麦克风距离、混响、设备差异，实验室 WER 5%，现场可能 30%；
- **领域术语识别差**：设备型号、专业名词必须做热词表或语言模型偏置；
- **方言口音**：通用模型对强口音退化明显，需要针对性数据；
- **长音频**：需要 VAD 切分 + 分段识别 + 时间戳对齐，否则内存与准确率都吃不消；
- **隐私合规**：语音是生物特征，存储与传输需加密，且涉及个人信息保护法规。

## 七、实践建议
1. **ASR 优先选 Whisper 系做基线**，实测 WER 后再考虑专用模型；
2. 所有 ASR 结果**必须做后处理**：标点恢复、数字规范化、领域术语替换；
3. 中文评估用 **CER** 而不是 WER（分词歧义会污染 WER）；
4. 实时场景先算 RTF 预算，再决定模型大小与是否用流式识别；
5. 声纹用于身份核验时，**必须叠加活体检测**。
