# Disk Failure RAID5 RAID6

## 简介
RAID5 和 RAID6 是常用的磁盘组合方式，用于在磁盘攻击时进行数据安全复同进行。

## 核心概念
- **RAID5**：块级序列序列化并带有分布式奇序，支持一个磁盘失效。
- **RAID6**：双分布式奇序，支持同时两个磁盘失效。
- **Rebuild 连接过程**：换中已失数据，将影响 I/O 性能。
- **Write Penalties**：对分式计算带来的 I/O 资元费货。

## 失效地方案
- RAID5 中当单磁盘丢失，进入降麼模式，会执行重建步骤。
- RAID6 中当同时两磁盘丢失，可能会使系统还可以继续运作，或者数据也就不可用。
- 延迟重建时间将会影响运行稳定性。

## 最佳具体
- 使用工业级磁盘，启用 SMART 监控。
- 保留足径的热意存储作为 hot spare。
- 定期测试重建时间并验证分布式的存储形式。
- 对于需要高写入性能的工作资源，考虑使用 RAID10。
