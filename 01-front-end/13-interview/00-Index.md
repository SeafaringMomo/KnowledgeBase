## 必考知识点

### JavaScript

- 闭包与作用域
- 原型与原型链
- 事件循环（Event Loop）
- Promise 与 async/await
- 浅拷贝与深拷贝
- 防抖节流
- 类型转换

### CSS

- 盒模型
- Flexbox 与 Grid
- 垂直居中
- BFC（块级格式化上下文）
- CSS 优先级
- 清除浮动

- HTTP 缓存（强缓存/协商缓存）
- HTTPS 与 TLS
- TCP 三次握手四次挥手
- CORS 跨域
- WebSocket

### 框架

- React 的 diff 算法
- Vue 的响应式原理
- 组件通信方式
- 状态管理方案
- Hooks 使用
