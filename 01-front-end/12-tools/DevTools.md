# 浏览器 DevTools

## Elements

- 查看/编辑 DOM 与 CSS
- 查看 Computed 样式
- 调试 Flex/Grid 布局
- 颜色对比度检查

## Console

```javascript
console.log('普通日志');
console.warn('警告');
console.error('错误');
console.table([{ name: 'Alice', age: 25 }]);
console.time('timer');
console.timeEnd('timer');
```

## Network

- 查看请求/响应头、状态码
- 分析加载瀑布流
- 模拟弱网环境
- 禁用缓存

## Performance

- 录制运行性能
- 分析长任务与重排重绘
- 查看主线程火焰图

## Application

- LocalStorage / SessionStorage
- IndexedDB
- Cookie
- Service Worker
- Cache Storage
