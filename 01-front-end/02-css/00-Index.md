## 核心概念

### 盒模型

```
┌─────────────────────────────────┐
│           Margin               │
│  ┌─────────────────────────┐   │
│  │         Border          │   │
│  │  ┌─────────────────┐    │   │
│  │  │      Padding    │    │   │
│  │  │  ┌───────────┐  │    │   │
│  │  │  │  Content  │  │    │   │
│  │  │  └───────────┘  │    │   │
│  │  └─────────────────┘    │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

- `box-sizing: content-box` — 默认，width = content
- `box-sizing: border-box` — width = content + padding + border（推荐）
