# INP 和 SOI 文件格式

## 简介
本章提供 INP 和 SOI 文件格式的概述，说明它们在数据采集与传感系统中的常见使用情况及其主要特征。

## 主要概念
- **INP**：包含二进制和文本版本形式，具有头部结构、常见字段。
- **SOI**：用于数据组多和信息定位，定义数据序列和元数据处理特性。
- **解析策略**：使用库函数、序列处理或数据结构属性的地方亮序读写转换。
- **转换**：将 INP 和 SOI 数据映射到常见格式（CSV，JSON 等）以便各种应用系统读取。

## 最佳工作方法
- 在处理前验证文件结构对类型的查询。
- 对大小文件使用流式读取，并使用后台包钙取访象象。
- 参考版本管理，注册协定版本和后退共同，让项目即时协作。
